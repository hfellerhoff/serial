## Bookmarks

Serial can now save articles and other pages with the browser extension. A
Bookmark keeps a sanitized readable copy and lives beside Feed items in the
same views, tags, Saved list, and reading workflow.

Open the extension on a page, connect it to the hosted service or your
self-hosted instance, and select **Save Bookmark**. You can assign views and
tags from the popup, create new ones, and add Feeds discovered on the page.
Saving the page again refreshes the Bookmark and starts its reading progress
from the beginning.

The capture path prefers the content extracted from the live page, falls back
to a bounded public-page fetch when necessary, and avoids duplicate Feed and
Bookmark entries for the same canonical URL.

Read the [Bookmark guide](/guides/saving-and-organizing-bookmarks) for the full
flow and privacy details.

## For self-hosters

The extension works with a current self-hosted Serial instance over trusted
HTTPS. This release adds bounded, DNS-pinned public HTTP fetching for fallback
capture and Feed discovery, a configurable instance-wide capture concurrency
limit, strict extension request limits, and initial Feed ingestion before an
extension add is reported complete.

See the [extension hosting guide](https://github.com/megaflorasoftware/serial/blob/beta/docs/hosting/extension.md)
for connection, security, configuration, and remote-media privacy guidance.
