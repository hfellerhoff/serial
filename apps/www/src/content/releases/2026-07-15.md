## Breaking changes

- Any shortcuts to `www.serial.tube` should be updated to use `app.serial.tube`.
- If you use the Serial PWA, you should reinstall from the `app.serial.tube` site.

Apologies for any disruption this may cause – this should be the only time this is necessary.

## Other improvements

- Added vim-style motions – you can now navigate between feed items using <kbd>H</kbd>, <kbd>J</kbd>, <kbd>K</kbd>, and <kbd>L</kbd>.
- Updated item animations to be more granular, reducing strange animation states.
